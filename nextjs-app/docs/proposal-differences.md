# What changed from the proposal

Checked against "Anino ng Ani: A Map of Martial Law's Promises and its Shadows in the Fields".

## Not built

- **Accounts and in-site proposals.** v1 has no accounts, database or admin queue. Contributions go through GitHub issue forms and pull requests, and a maintainer reviews every change. This is also an addition, because the proposal did not name GitHub.
- **Embedded videos.** No video was added. The component stays in the code and is hidden when unused, and this project makes no claim of embedded video.
- **UPLB theses and DA or PhilRice releases.** None is cited. A search found one UPLB thesis on Calamba tenant-farmers under leasehold (1987), but its full text is not in the UPLB repository and it covers leasehold, not a program page. It is listed as a lead in the gaps. No DA or PhilRice release was found that names a place in the five provinces and states an effect there. The archives the proposal names (The Republic, UP Diktadura, Martial Law Museum, Supreme Court, Official Gazette) are used.

## Built differently

- **Five topics, not six program families.** The topics merge the proposal's six families, and the filters work the same way.
- **"Today's programs" became "from then to now".** No sourced link between a martial-law program and a program of today was found. The landing page lists dated records from 2000 onward, taken from the program pages, and makes no echo claim. Links between then and now are labeled as interpretation.
- **Four charts.** Land transfer, Masagana 99 credit, the coconut levy, and fishpen area on Laguna de Bay. Each figure shows its scope and source.

## Added

- **Reading notes and "ask at a relative"** on the About page, for the proposal's implications and family-questions items.
- **A landing hero.** It uses a credited image only if one passes the license rules, and a drawn fallback otherwise. The site currently ships the fallback.
